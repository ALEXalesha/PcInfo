# PcInfo

**В планах.** Утилита для Windows, которая показывает, что внутри ПК: видеокарта, процессор, планки памяти и их
частота, диски со SMART, материнская плата, мониторы и Windows; температуры и нагрузка живыми графиками с
предупреждением о перегреве; USB-устройства и открытые сетевые порты с программой, которая держит каждый.

[English version](README.md)

## Состояние

Кода пока нет. План согласован 23.10.2026, работа стоит в очереди. Этот README описывает план, а не готовую
программу.

## Что будет показывать

| Блок | Что |
|---|---|
| Железо | Видеокарта, процессор, память (планки, частота, тайминги, если Windows их отдаёт), диски и SMART, материнская плата, мониторы, версия Windows |
| Датчики | Температуры, частоты, вентиляторы и нагрузка живыми графиками; предупреждение при перегреве |
| Порты и устройства | USB-устройства, открытые сетевые порты и какая программа слушает каждый |
| Быстрые тесты | Пропускная способность памяти и короткая проверка своего буфера (не полный memtest), скорость диска на временном файле, который потом удаляется |

Отчёт «мой ПК» сохраняется без серийных номеров, MAC-адресов, UUID и имён пользователя и компьютера.

## Как будет устроено

- C# .NET 8 WPF, те же темы, что у Paint Pro, данные через LibreHardwareMonitorLib и WMI.
- Части датчиков нужны права администратора и драйвер датчиков; без них программа пишет, чего не хватает, а не
  падает.
